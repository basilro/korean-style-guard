이 함수는 문자열 목록을 받아 중복을 없애고 길이순으로 정렬한 뒤 돌려준다.

```python
def unique_sorted(items):
    seen = set(items)
    return sorted(seen, key=len)
```

먼저 `set`으로 바꾸는 것이 핵심이다. 집합은 같은 값을 두 번 담지 않기 때문에 중복이 자연스럽게 사라진다. 다만 집합은 순서를 보장하지 않으므로, 입력의 원래 순서를 유지해야 한다면 이 방식은 쓸 수 없다. 그런 경우에는 `dict.fromkeys`를 쓸 수밖에 없다.

`sorted`는 새 목록을 만들어 반환하고 원본은 건드리지 않는다. 항목이 수십만 개로 늘어날수록 정렬 비용이 커지지만, 보통은 문제가 되지 않는다. 길이가 같은 문자열끼리는 입력에서 나타난 순서가 아니라 집합의 내부 순서를 따르게 되니 주의해야 한다.

이 함수를 호출하는 쪽에서 빈 목록을 넘겨도 오류는 나지 않는다. 빈 목록을 돌려줄 뿐이다. 반대로 `None`을 넘기면 `TypeError`가 발생하는데, 이 문제를 막고 싶다면 함수 앞부분에서 입력을 검사해야 한다. 지금은 아무 검사도 하지 않고 있으므로 호출하기 전에 값을 확인하는 것이 안전하다. 실수로 숫자 목록을 넘겨도 `len`이 실패하기 때문에 같은 오류를 만나게 된다.
