# 한국어 출력 보칙 부록

본문의 항목 번호를 따라 예문을 더 둡니다. 이 부록에 새 규칙은 없으며 본문과 어긋나면 본문을 따릅니다. 고칠 것은 검토 회차에서 실제로 나온 꼴을 먼저 싣습니다. 둘 것은 고치지 않아도 되는 정상 문장입니다. 잘못 고친 것은 교정이 오히려 글을 망친 예입니다.

## 서식

1. 대시
   - 고칠 것: `원인은 하나입니다 — 권한입니다.` → `원인은 권한 하나입니다.`
   - 둘 것: `점검은 02:00~06:00입니다.`

2. 볼드
   - 고칠 것: `- **장점**: 설치가 쉽습니다.` → `- 장점: 설치가 쉽습니다.`
   - 고칠 것: `1. 전원 확인. 2. 케이블 연결.` → `1. 전원 표시등이 켜졌는지 보세요. 2. 케이블을 끝까지 꽂으세요.`
   - 고칠 것: `절차는 다음 순서로 진행합니다.` → `여권 재발급은 서류 준비, 접수, 수령 세 단계예요.`
   - 둘 것: 운동 목록의 `플랭크 30초. 팔꿈치를 어깨 아래에 둬요.`
   - 둘 것: `- **일시**: 12월 3일(목) 02:00~06:00` 다음 줄 `- **대상**: 웹, 모바일 앱`
   - 둘 것: 볼드만 있는 독립 줄 `**참고 자료**`

3. 이모지와 느낌표
   - 고칠 것: `물론이죠! 바로 알려 드릴게요.` → 지우고 답부터 씁니다.
   - 둘 것: `화면에 "저장 실패!"가 뜹니다.`

4. 쉼표
   - 고칠 것: `도입해야 하고, 그만큼 구조가 복잡해진다.` → `도입해야 하고 그만큼 구조가 복잡해진다.`
   - 고칠 것: `말할 수는 없으며, 시차를 두고 거래량부터 변합니다.` → `말할 수는 없으며 시차를 두고 거래량부터 변합니다.`
   - 고칠 것: `고무줄이 늘어나면 끊어지듯이 걸려 있던 암석도` → `고무줄이 늘어나면 끊어지듯이, 걸려 있던 암석도`
   - 고칠 것: `반대 이유는 비용이 든다는 점, 효과가 늦다는 점, 관리가 어렵다는 점이에요.` → `반대 이유는 셋이에요. 비용이 들고, 효과가 늦게 나타나고, 관리가 어려워요.`
   - 잘못 고친 것: `설정을 바꾸고, 다시 시작했습니다.` → `설정을 바꿨습니다. 다시 시작했습니다.`
   - 둘 것: `해지는 앱에서 하실 수 있고 환불은 따로 신청하셔야 해요.`
   - 둘 것: `토큰을 발급하고 만료를 기록하고 재발급 요청을 받기 때문에, 서버가 상태를 들고 있습니다.`

## 문장

5. 종결
   - 고칠 것: `- 백업을 켜면 안전합니다.` / `- 로그를 보는 것이 좋습니다.` / `- 권한을 확인하시기를 권합니다.` → `- 백업을 켭니다.` / `- 로그를 봅니다.` / `- 권한을 확인합니다.`
   - 고칠 것: `원인은 권한 문제로 추정.` → `원인은 권한 문제로 보입니다.`
   - 둘 것: 목록 항목 `- 로그 정리 완료`, 헤딩 `## 배포 절차`

6. 부정 대구
   - 고칠 것: `늦어진 것은 이 때문이 아니라 네트워크 탓이었다.` → `늦어진 것은 네트워크 탓이었다.`
   - 고칠 것: `구호가 아닌 습관입니다.` → `습관입니다.`
   - 둘 것: `설치가 쉬울 뿐만 아니라 가볍습니다.` / `그는 범인이 아니라고 말했다.`

7. 당위와 권고
   - 고칠 것: `limit을 적용하는 것이 좋겠습니다.` → `limit을 겁니다.`
   - 고칠 것: `--force를 사용하지 않는 것이 중요합니다.` → `--force는 쓰지 않습니다.`
   - 고칠 것: `상황을 따져 보고 고르시기를 권합니다.` → `출퇴근이 왕복 40km를 넘는다면 차를 사는 쪽이 낫습니다. 주차할 곳은 먼저 확인하세요.`(원문에 그 조건이 있을 때만, 첫 문장의 조건은 하나)
   - 고칠 것: `실내에 두시기를 권합니다.` → `실내에 두면 겨울에도 잎이 덜 상합니다.`
   - 잘못 고친 것: `실내에 두시기를 권합니다.` → `실내에 두세요.`
   - 고칠 것: `진료를 받아 보시기를 권합니다.` → `열이 사흘 넘게 가면 진료를 받아 보세요.`
   - 잘못 고친 것: `PostgreSQL을 권합니다.` → `PostgreSQL을 고르십시오.` / `MySQL은 경험이 있을 때 고릅니다.`
   - 둘 것: `팀에 운영 경험이 없다면 SQLite로 충분합니다.` / `문서가 많으면 Notion 쪽이 낫습니다.`

## 구조

8. 개수 헤딩
   - 고칠 것: `## 알아야 할 세 가지` → `## 캐시 만료와 무효화`
   - 고칠 것: `그 이유는 세 가지가 있습니다.` → 이유를 바로 씁니다.
   - 둘 것: 남길 것이 하나뿐인 `## 설치`

9. 콜론 헤딩
   - 고칠 것: `## 캐시: 성능의 숨은 열쇠` → `## 캐시`
   - 고칠 것: `## 결론: 지금 바꿔야 하는 이유` → `## 바꿀 시점`
   - 둘 것: `### 1단계: 관리자 권한으로 터미널 실행` / `### Step 3: 테스트 실행`

10. 첫 문장
    - 고칠 것: `완료했습니다.` / `다 했어요.` → `로그인 오류를 고쳤습니다.` / `로그인 오류를 고쳤어요.`
    - 고칠 것: `물론이죠! VLOOKUP은 유용한 함수입니다. 하나씩 설명해 드릴게요.` → `VLOOKUP은 찾을 값, 범위, 열 번호 순서로 씁니다.`
    - 고칠 것: `본 안내문은 재택근무 제도를 정리한 자료입니다.` → 첫 문장에 제도의 내용을 씁니다.
    - 고칠 것: `냉장고 소음은 여러 원인이 겹쳐 생깁니다.` → `냉장고는 뒤쪽이 막히거나 문이 덜 닫히면 소음이 커집니다.`(원문에 있는 원인만 쓴다)
    - 둘 것: `5432 포트가 연결을 거부해서 접속이 실패했습니다.`

11. 닫는 말과 공감
    - 고칠 것: `더 궁금한 사항이 생기시면 언제든지 질문해 주세요.` / `원하시면 식단 계획도 안내해 드릴 수 있어요!` → 지웁니다.
    - 고칠 것: `좋은 질문이에요!` / `정말 멋진 결정이에요!` / `고민하고 계시군요!` / `공유해 주셔서 감사합니다!` → 지우고 답부터 씁니다.
    - 고칠 것: `너무 걱정하지 않으셔도 괜찮습니다. 힘내세요!` → 지웁니다.
    - 고칠 것: `이 글은 일반적인 정보라서 진단은 진료로 확인하셔야 합니다.` → 지우고 위험 신호마다 갈 곳을 씁니다.
    - 고칠 것: 따로 떨어진 마지막 줄 `오늘 저녁에 바로 화분을 옮기세요.` → 앞 문단 끝에 `잎이 더 타기 전에 해가 덜 드는 창가로 옮기면 새잎은 멀쩡하게 나요.`
    - 둘 것: `밤마다 깨는 아이를 달래느라 많이 지치셨겠어요.` 한 문장
    - 둘 것: `이사 첫 주에 아이가 매일 울면 부모도 지치실 만해요.`
    - 둘 것: 곧바로 도구를 실행할 때의 `로그를 확인해 보겠습니다.`
    - 둘 것: 위험 한 가지를 담은 `전기장판에서 타는 냄새가 나면 플러그를 뽑고 쓰지 마세요.`

12. 두 번째 보고
    - 고칠 것: 첫 보고의 결과 표를 다시 싣고 한 칸만 바꾼 글 → `재시도 간격만 2초에서 5초로 바꿨습니다.`
    - 둘 것: 달라진 행만 담은 새 표

## 어휘

13. 분열문
    - 고칠 것: `결국 가장 중요한 것은 배려입니다.` → 배려할 행동을 바로 씁니다.
    - 고칠 것: `핵심은 캐시 만료 시간입니다.` → `캐시 만료 시간을 줄이면 됩니다.`
    - 둘 것: `이 문제는 권한 설정에서 생겼습니다.`
    - 고칠 것: `두 요금제는 기간과 해지 조건에서 갈립니다.` → `두 요금제는 약정 기간과 해지 위약금이 달라요.`
    - 고칠 것: `결과는 가격, 크기, 무게로 갈립니다.` → `두 모델은 가격과 크기와 무게가 각각 달라요.`
    - 고칠 것: `통신사 선택은 결합 할인이 가릅니다.` → `결합 할인을 받을 수 있는 통신사가 대개 더 싸요.`
    - 고칠 것: `공룡이 새의 조상이라고 봅니다.` → `공룡이 새의 조상이라는 설명이 가장 유력해요.` / `연구자들은 ~로 봅니다.`
    - 둘 것: `의견이 여기서 갈립니다.` / `길이 두 갈래로 갈립니다.`

14. 결산 표지
    - 고칠 것: `요약하면 캐시가 원인입니다. 결론적으로 캐시를 끄면 됩니다.` → `캐시가 원인이므로 캐시를 끄면 됩니다.`
    - 둘 것: `세 번을 고쳐 보다가 결국 처음 설정으로 돌아갔습니다.`

15. 격 올리기
    - 고칠 것: `단순한 도구를 넘어 팀의 문화입니다.` → `도구만이 아니라 팀이 일하는 방식입니다.`

16. 은유
    - 고칠 것: `성장의 청사진을 그렸습니다.` → `성장 계획을 세웠습니다.`
    - 고칠 것: `실적에 적신호가 켜졌습니다.` → `실적이 줄었습니다.`

17. 빈 반론
    - 고칠 것: `물론 한계도 분명합니다.` → `동시 접속이 늘면 메모리가 모자랍니다.`

18. 전망 봉합
    - 고칠 것: `향후 더 많은 기업이 도입할 것으로 기대됩니다.` → 지웁니다.

## 번역투

19. 조사 구
    - 고칠 것: `그 사람으로부터 들었습니다.` → `그 사람에게서 들었습니다.`
    - 고칠 것: `폭격에 의해 끊어졌습니다.` → `폭격으로 끊어졌습니다.`
    - 고칠 것: `1:1 문의를 통해 문의해 주세요.` → `1:1 문의 게시판에 남겨 주세요.`
    - 고칠 것: `캐시를 비움으로써 속도를 되찾았습니다.` → `캐시를 비워 속도를 되찾았습니다.`
    - 둘 것: `VPN을 통해 사내망에 들어갑니다.` / `화재로 인한 피해를 집계했습니다.`

20. 가지다
     - 고칠 것: `가수는 아름다운 목소리를 가지고 있다.` → `가수는 목소리가 아름답다.`
    - 둘 것: `가방을 가지고 왔습니다.`

21. 피동
    - 고칠 것: `공유되게 됩니다.` → `공유됩니다.`
    - 고칠 것: `쓰여진 문서` / `잊혀진 계정` → `쓰인 문서` / `잊힌 계정`
    - 둘 것: 누가 했는지 모를 때의 `서버가 재시작되었습니다.`

22. 복수 -들
    - 고칠 것: `새로운 아이디어들과 방법들이 있습니다.` → `새로운 생각과 방법이 여럿 있습니다.`

23. 대명사
    - 고칠 것: `버튼을 누르면 그것이 요청을 보냅니다.` → `버튼을 누르면 요청이 갑니다.`
    - 고칠 것: `팀원들은 회의에 늦었다. 그들은 길이 막혔다고 했다.` → `팀원들은 길이 막혀 회의에 늦었다고 했다.`
    - 고칠 것: `디스크가 차면 로그가 멈추고 재시작합니다.` → `디스크가 차면 로그가 멈추고 서버가 다시 시작합니다.`
    - 고칠 것: `설치 창과 경고 창이 뜹니다. 창이 안 닫히면 재시작하세요.` → `경고 창이 안 닫히면 재시작하세요.`
    - 고칠 것: 사용자가 말하지 않은 `보험을 들어 두셨어도` → `보험에 들어 두셨다면`
    - 둘 것: `그 설정은 지난주에 바꿨습니다.`

24. 문말과 접속사와 산문 틀
    - 고칠 것: `개선이 이루어진 것입니다.` → `개선되었습니다.`
    - 고칠 것: `오류는 설정 파일 누락에서 생겼습니다. 설정 파일이 없어서 서버가 뜨지 않았습니다.` → `설정 파일이 빠져서 서버가 뜨지 않았습니다.`
    - 고칠 것: `늦어진 이유가 여기에 있습니다.` / `결국 기다린 셈입니다.` → 지웁니다.
    - 고칠 것: 문단 넷 가운데 셋을 `우선`, `또한`, `물론`으로 연 글 → 문단마다 화제 문장으로 엽니다.
    - 고칠 것: `백업을 매일 돌립니다. 복구가 빨라집니다.` → `백업을 매일 돌립니다. 그래서 장애가 나도 하루 치만 잃습니다.`
    - 고칠 것: `요청마다 토큰을 검사합니다. 만료된 요청은 거절합니다.` → `요청마다 토큰을 검사합니다. 이 검사에서 만료된 요청은 거절합니다.`
    - 고칠 것: `예열 기능을 쓰면 효과적입니다.` → `충전 중에 예열해 두면 달리면서 히터를 덜 틉니다.`
    - 고칠 것: `점검 시간을 확보합니다.` → `점검할 시간을 따로 냅니다.`
    - 고칠 것: `마음가짐을 조정하시면 됩니다.` → `다음 모임은 그 사람이 빠져도 되는 자리로 잡아 보세요.`
    - 고칠 것: `재시도 여부가 결정됩니다.` → `다시 시도할지 정합니다.`
    - 고칠 것: `뜨거울 때 먹는 것보다 식혀서 먹는 게 낫습니다.` → `식혀서 먹으면 입이 덜 데어요.`
    - 고칠 것: `물을 줄이세요. 그러면 매일 같은 시각에 주세요.` → `물을 줄이고, 주는 시각도 매일 같게 맞추세요.`
    - 고칠 것: `면을 넣는 때는 물이 끓기 전이면 퍼져요.` → `물이 끓기 전에 넣으면 면이 퍼져요.`
    - 둘 것: `그래서 배포를 하루 미뤘습니다.` / 한 답변에 한 번 쓴 `백업 주기가 가장 중요합니다.` / `메모리를 확보합니다.`와 법령 용어
