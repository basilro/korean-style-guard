# korean-style-guard

AI 에이전트가 쓰는 한국어를 사람이 쓴 글처럼 읽히게 다듬고, 이미 쓴 한국어 문서를 교정·교열하는 플러그인입니다. Claude Code와 Codex CLI에서 작동합니다.

첫째로 에이전트의 답변을 다듬습니다. 에이전트가 쓴 한국어에는 엠대시(—), 지나치게 많은 볼드, `결론적으로` 같은 맺음말, `~를 통해` 같은 번역투가 자주 섞입니다. 이 플러그인은 한국어 문체 규칙 38항목(보칙)을 세션에 넣어 이런 표현을 처음부터 덜 쓰게 하고, 답변이 끝나면 규칙을 어긴 곳을 찾아 다시 쓰게 합니다.

둘째로 이미 쓴 문서를 교정·교열합니다. 사람이 쓴 공지, 보고서, 메일을 맡기면 흔한 오기(`몇일`, `금새`), 외래어 오표기(`메세지`, `컨텐츠`), 띄어쓰기와 문장 부호, 호응이 어긋난 문장을 고칩니다. 글쓴이의 말투는 그대로 둡니다.

아래 두 문장은 고치기 전의 예로 일부러 지은 것입니다. 첫 문장은 AI가 흔히 쓰는 꼴(엠대시, 볼드, 느낌표, `결론적으로`, 추측을 겹친 `~할 수 있을 것입니다`)을, 둘째 문장은 사람이 흔히 틀리는 교정 오류(`금번`, `하기와 같이`, `메세지`, `몇일`)를 담고 있습니다.

## 주요 기능

- 세션을 시작할 때 보칙을 자동으로 넣습니다.
- 답변이 끝나면 보칙 위반을 세고, 걸리면 서식을 고쳐 다시 쓰게 합니다.
- 한국어로 물었는데 영어로 답하면 한국어로 다시 쓰게 합니다.
- 에이전트가 파일을 쓰거나 고치면 문서는 문체와 교정 오류를, 코드는 한글 이름이 섞였는지 검사합니다.
- `/ko-check` 명령과 `ko-style` 스킬로 이미 쓴 글을 점검하고 교정·교열합니다. 위반 보고에는 바른 꼴(`디렉토리→디렉터리`)이 함께 나옵니다.
- 답을 처음부터 보칙에 맞게 쓰는 output style을 함께 줍니다.

## 장점

- 규칙을 알려 주는 데서 그치지 않고 지켰는지 검사합니다. 지침만 적어 두면 금지한 부호도 계속 나오기 때문입니다.
- 규칙은 사람 글(국어학 논문, 위키백과, 웹소설)과 AI 답변에 같은 검사기를 돌려 빈도를 견준 뒤 정했습니다. 사람 글에도 흔한 표현은 되풀이될 때만 셉니다.
- 교정·교열 항목은 국내 교정·교열 연구 37편을 근거로 골랐고, 오탐이 낮은 것만 검사기에 넣었습니다.
- 블라인드 시험에서 답변의 사람 말투, 이해, 내용 점수가 이전 버전보다 모두 높았습니다. 사람이 쓴 문서 10편에 심은 오류 52개는 44개를 바로잡았습니다(이전 버전은 36개).
- 파이썬 표준 라이브러리만 쓰고 검사는 모두 컴퓨터 안에서 끝납니다.

## 한계

- 검사기는 기계로 셀 수 있는 표현만 봅니다. 문장이 어색한지, 내용이 맞는지는 판단하지 못합니다.
- 답변 검사는 서식만 고치게 하므로 사실 오류나 앞뒤가 안 맞는 내용은 그대로 남을 수 있습니다.
- 교정에서 뜻으로 가려야 하는 말(`결재`와 `결제`, `-던지`와 `-든지`)과 수식 관계가 모호한 문장은 기계로 잡지 못해 에이전트의 판단에 맡깁니다. 시험에서도 이런 문장을 가장 많이 놓쳤습니다.
- 규칙이 엄격해서 사람이 쓴 글도 걸릴 때가 있습니다. 파일 검사와 언어 판정은 환경 변수로 끌 수 있지만, 답변의 문체 검사는 끌 수 없습니다.
- 코드 검사는 문자열 안을 보지 않으므로 `{"이름": 1}` 같은 한글 키는 놓칩니다.

## 설치

파이썬 3.8 이상과 bash가 필요합니다. Windows에서는 Git Bash를 설치하세요.

### Claude Code

Claude Code 세션 안에서 아래 두 명령을 입력합니다. 다음에 여는 세션부터 적용됩니다.

```
/plugin marketplace add basilro/korean-style-guard
/plugin install korean-style-guard@korean-style-guard
```

새 버전으로 갱신할 때는 터미널에서 마켓플레이스 목록을 먼저 받습니다.

```bash
claude plugin marketplace update korean-style-guard
claude plugin update korean-style-guard
```

### Codex CLI

Codex에서는 저장소를 받아 설치 스크립트를 실행합니다.

```bash
git clone https://github.com/basilro/korean-style-guard.git
cd korean-style-guard
codex/install.sh
```

설치한 뒤 Codex의 `/hooks`에서 새로 들어간 훅 네 개를 신뢰한다고 표시해야 작동합니다. 훅은 내려받은 저장소 안의 스크립트를 부르므로 저장소 폴더는 지우거나 옮기지 마세요.
