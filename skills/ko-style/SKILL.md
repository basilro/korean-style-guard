# 한국어 문체 점검

이 스킬은 이미 쓰인 한국어 글을 대상으로 한다. Claude 자신의 답변은 Stop hook 이 자동으로 검사하므로 여기서 다룰 필요가 없다.

## 무엇을 세는가

`scripts/ko_style_check.py` 가 여덟 항목 중 기계로 셀 수 있는 것을 센다. 코드 블록과 인라인 코드와 인용은 검사에서 뺀다. 저자가 쓴 것이 아니기 때문이다.

| 항목 | 허용 |
|---|---|
| 엠대시(—)와 엔대시(–) | 0 |
| 완결 문장을 감싼 볼드 | 0 |
| 줄머리에서 문단을 여는 볼드 | 0 |
| `**라벨**:` 형태 | 0 |
| 볼드 총량 | 3 |
| 이모지 | 0 |
| 느낌표 | 0 |
| 개수를 예고하는 헤딩 | 1 |

## 점검만 할 때

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ko_style_check.py" <파일>
cat <파일> | python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ko_style_check.py" --json
```

위반이 없으면 0, 있으면 1 로 끝난다.

## 고칠 때

1. 검사기를 돌려 무엇이 몇 건인지 센다.
2. 검출된 자리를 고친다. 아래 방향을 따른다.
   - 엠대시는 문장을 완결하고 새 문장으로 잇거나, 콜론이나 접속사로 바꾼다.
   - 완결 문장 볼드는 강조를 푼다. 문단을 라벨이 아니라 화제 문장으로 연다.
   - `**라벨**:` 은 서술어가 있는 문장으로 편다.
   - 개수를 예고하는 헤딩은 개수 대신 내용을 쓴다.
   - 이모지와 느낌표는 지운다. 프로그램 출력을 인용한 것은 예외다.
3. 다시 검사해 0 건인지 확인한다.
4. 무엇을 몇 건 고쳤는지만 알린다.

## 하지 말 것

내용을 바꾸지 않는다. 서식과 구조만 다룬다. 사실·이름·숫자·날짜·인용을 더하거나 빼면 안 된다.

기술 문서에서 관용으로 굳은 비유는 그대로 둔다. 뜻만 남기고 읽는 맛을 없애는 방향으로 고치지 않는다.

인용문과 코드와 프로그램 출력 안의 표현은 건드리지 않는다.
